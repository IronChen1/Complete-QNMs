# Kerr spectrum: nonextremal and extremal Kerr black holes

The workbook contains gravitational Kerr QNM data for ell = 2, 3 and Schwarzschild parent overtones 0 through 41. Each overtone has its own worksheet, with nonextremal samples and a/M = 1 endpoints ordered together. The endpoint_type column distinguishes isolated extremal roots from zero-damping accumulation limits. All stored source digits are retained as text.

Use plot_qnm.m, plot_qnm.py, or plot_qnm.wl to visualize the data. The MATLAB program preserves the original plotting style and datatip configuration.

Earlier L2, L3, and L4 datasets are preserved in ../Old_Version.
